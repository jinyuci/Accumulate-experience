基于 UCI Online Retail 数据集的零售分析项目，覆盖数据清洗、RFM 客户分层、产品分析和时间节奏分析。

## 分析框架

### 数据清洗
- CustomerID 缺失 135,080 行：匿名批发客户或未注册用户
- 退货 10,624 行：采用 Quantity < 0 口径，比 InvoiceNo C 开头多覆盖 12.6%
- 异常单价 2,517 行：UnitPrice <= 0，已从分析中排除

### 客户分析（RFM）
- 含金额维度的完整 RFM 模型：Recency + Frequency + Monetary
- 8 类客户分层：重要价值、重要挽留、重要发展、一般发展、重要保持、一般保持、一般价值、一般挽留

### 产品分析
- 热销商品 Top 10（按销量）
- 退货率排名：基于 Quantity < 0 / Quantity > 0 计算
- 商品单价分布：按区间（0-1 / 1-5 / 5-10 / 10-50 / 50-100 / 100-500 / 500+）统计

### 时间分析
- 月度趋势：9-11 月为旺季，11 月全年最高（£116 万）
- 星期分布：周六零交易，周日极少（<5%），工作日为主力
- 时段分布：92% 交易集中在 9:00-16:00，17:00 后几乎无交易
