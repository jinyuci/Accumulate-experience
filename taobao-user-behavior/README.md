# 淘宝用户行为分析

基于阿里云天池公开数据集的电商用户行为分析项目，完整链路包括：数据清洗、AARRR 模型分析、RFM 用户分层、Tableau 仪表板搭建。

---

## 数据概览

| 指标 | 数值 |
|------|------|
| 数据来源 | 阿里云天池 UserBehavior.csv |
| 原始数据量 | 112,900,807 行 |
| 有效数据量 | 112,838,214 行 |
| 时间范围 | 2017-11-25 ~ 2017-12-03（9 天）|
| 字段 | 用户ID、商品ID、品类ID、行为类型、时间戳 |
| 行为类型 | pv（浏览）、cart（加购）、fav（收藏）、buy（购买）|

---

## 分析框架：AARRR 模型

### 用户获取
- 日均 PV 1,080 万，日均 UV 73 万，人均浏览深度（PV/UV）约 15
- 周末 PV 较工作日高 35%，12 月 2 日（周六）达到峰值 1,391 万
- 分时段活跃高峰为 18:00-23:00，峰值 20:00

### 用户激活
- 行为类型分布：pv 89.6%、cart 5.5%、fav 2.9%、buy 2.0%
- 独立用户维度：9 天内仅 2.0% 的用户发生过购买

### 用户留存
- 次日留存率 78%-98%，三日留存率 76%-99%
- 双十二预热期间留存率持续走高，最后两天超过 98%

### 用户变现
- 同人同商品口径：浏览到加购/收藏转化率 5.26%，浏览到购买 1.84%
- 购买用户中复购率 16.3%（9 天内购买 2 次及以上）

### 用户分层
- RFM 四象限结果：重要价值 34.3%、重要发展 33.3%、重要保持 24.1%、重要挽留 8.3%

---

## 商品分析

- 热门商品 Top 10（按浏览量）
- 热销商品 Top 10（按购买量），单品转化率最高 78.5%
- 高转化品类 Top 10，最高品类转化率 99.7%
- 品类四象限：明星品类 5.3%、利基品类 8.7%、流量浪费 1.2%、长尾 84.8%
